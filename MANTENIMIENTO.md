# Mantenimiento de la web

## Archivos

| Archivo | Contenido |
| --- | --- |
| `index.html` | Textos, secciones y enlaces de la web. |
| `styles.css` | Colores, tipografía y diseño adaptable. |
| `favicon.svg` | Icono de marca. |
| `.nojekyll` | Desactiva el procesamiento de Jekyll. |
| `README.md` | Presentación pública del repositorio. |

## Publicación

Repositorio: `nexobyte-tech-hq/nexobyte-tech-hq.github.io`.

Los archivos deben estar directamente en la raíz de la rama `main`. En **Settings → Pages**, la fuente es **Deploy from a branch → main → /(root)**.

Después de guardar un cambio, revisa el despliegue en **Actions**. La web se publica en https://nexobyte-tech-hq.github.io/.
